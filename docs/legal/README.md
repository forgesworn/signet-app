# MySignet publisher information

**Repository drafts, 23 October 2026: unadopted; not legal advice or reviewed by a lawyer.** Application 0.22.1 is released from `335e1f6615f7db6fbcd8b5b5dfa9fdb6d0113667`. Application release does not adopt these documents.

The working position is public software publication with static hosting and independently operated relay/storage defaults. The owner's separate relay serves only their identities, devices and automations. This is a reasoned, provisional scope position, not a blanket OSA exemption. There is no separate operating legal entity; no company, business status or natural-person identity is inferred.

The current package is deliberately small:

- [Scope position](position.md): what is published/hosted, the separate relay and when to reassess.
- [Short privacy draft](privacy-notice.md): website/update requests, device processing, default recipients and contact rights.
- [Software/privacy/security contact draft](report-handling.md): ordinary contact handling and practical limits.
- [Remaining inputs](open-items.md): the current short list, maintained separately.

For the actual publisher processing, the remaining inputs for adoption are a working private contact route, identification of the applicable controller role, adoption of appropriate hosting/contact bases, and an accurate account of relevant provider arrangements/retention. The inbox is not yet supplied; no address is invented. A company, minimum-age policy, managed-verification programme or OSA reporting system is not prescribed for a static software publisher.

Children's-code/DPIA, assurance claims, donor records and regulated-service procedures need a separate scoped assessment only if the actual processing, offering or claims justify it. The app's child/guardian features do not establish that the publisher receives children's documents. General ForgeSworn donations do not establish a paid MySignet service.

Evidence: [sanitised application, hosting and recipient evidence](evidence.md). These repository drafts describe verified facts and remaining decisions; they are not an adopted web privacy policy or a commitment to operate additional services.
