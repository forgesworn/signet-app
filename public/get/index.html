MySignet for Android

The native app adds what a web page can't: fingerprint unlock, and an always-on approvals service that keeps working with the screen off — all with no Google services. Built for GrapheneOS.

Install it (GrapheneOS / Android)

  1. Tap Download the APK above. When your browser asks, allow it to install apps this once.
  2. Open the downloaded file and tap Install.
  3. GrapheneOS network permission: open the app once. If it can't reach the network, go to Settings → Apps → MySignet → Network and turn it on. (On GrapheneOS an app — especially just after an update — can start with network access off; this looks like a connection error until granted.)
  4. When the app offers always-on serving, allow the battery-optimisation exemption and notifications it asks for — that's what lets it alert you to a child's request while the screen is off.
  5. Set up fingerprint unlock in the app (Settings → Security). You'll need a screen lock + a fingerprint enrolled on the phone first.

On Zapstore

Prefer a store? MySignet is on Zapstore, the Nostr-native app store — same signed APK, auto-updates, and the publisher identity is verifiable end-to-end.

Auto-updates with Obtainium (optional)

Prefer hands-off updates? Add https://mysignet.app/get as an HTML source in Obtainium and it will pick up new signed builds as they're published (the versioned link below is what it watches). Every update is signed with the same key, so it installs over the top cleanly.

Machine-readable: signet-app.json (version, SHA-256, signing-cert digest — what the app itself checks against).

On iPhone or a computer?

There's no APK for you — just use the web app at mysignet.app. It does everything except native fingerprint unlock and always-on background serving, which are Android-only for now.
