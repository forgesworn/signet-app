Five minutes

Install it (GrapheneOS / Android)

The same steps work on any Android phone. The GrapheneOS notes only matter if that's what you run.

  1. Tap Download the APK above. When your browser asks, allow it to install apps this once.
  2. Open the downloaded file and tap Install.
  3. GrapheneOS network permission: open the app once. If it can't reach the network, go to Settings → Apps → MySignet → Permissions → Network and turn it on. (On GrapheneOS an app — especially just after an update — can start with network access off; this looks like a connection error until granted.)
  4. When the app offers always-on serving, allow the battery-optimisation exemption and notifications it asks for — that's what lets it alert you to a child's request while the screen is off.
  5. Set up fingerprint unlock in the app (Settings → Security & Backup). You'll need a screen lock + a fingerprint enrolled on the phone first. Fingerprint unlock needs Android 11 or later; older phones use a 6-digit PIN.

Then, in the app

  1. 1Tap Create my Signet, or I already have a Signet to restore.
  2. 2Lock it with your fingerprint or a 6-digit PIN.
  3. 3Write your 19 recovery words on paper: Settings → Security & Backup → Backup Words.

Other ways to install

Prefer a store, or hands-off updates?

Every route gives you the same signed APK.

On Zapstore

Prefer a store? MySignet is on Zapstore, the Nostr-native app store — same signed APK, auto-updates, and the publisher identity is verifiable end-to-end.

Auto-updates with Obtainium

Optional. Add https://mysignet.app/get as an HTML source in Obtainium and it will pick up new signed builds as they're published (the versioned link below is what it watches). Every update is signed with the same key, so it installs over the top cleanly.

Current build: not published yet

Machine-readable: signet-app.json (version, SHA-256, signing-cert digest — what the app itself checks against).

On iPhone or a computer?

There's no APK for you — just use the web app at mysignet.app. It does nearly everything. Native fingerprint unlock, always-on background serving, tap-and-Bluetooth Handshake and signing for other Android apps are Android-only for now.

MySignet is client-side identity for the Signet protocol — your keys stay on your device.
